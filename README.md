# Проект Customer banking operations

## Описание:
Проект Customer banking operations - это виджет, который показывает несколько последних успешных банковских операций клиента.

## Установка:

1. Клонируйте репозиторий:
```
git clone https://github.com/username/project-x.git
```
2. Установите зависимости:
```
pip install -r requirements.txt
```
## Использование:

1. Откройте приложение в вашем веб-браузере.
2. Маскируйте номер карты и счет, оставляя тип карты.
3. Преобразуйте вид даты.
4. Сортируйте данные о транзакциях.
