# Проект Customer banking operations

## Описание:
Проект Customer banking operations - это виджет, который показывает несколько последних успешных банковских операций клиента.

## Установка:

1. Клонируйте репозиторий:
```
git clone https://github.com/username/project-x.git
```
2. Установите зависимости:
```
pip install -r requirements.txt
```
## Использование:

1. Откройте приложение в вашем веб-браузере.
2. Маскируйте номер карты и счет, оставляя тип карты [widget.py](src/widget.py)[masks.py](src/masks.py).
3. Преобразуйте вид даты из модуля [widget.py](src/widget.py).
4. Сортируйте данные о транзакциях по дате, а также по возрастанию и убыванию в модуле [processing.py](src/processing.py).
5. Поочередно сортируйте по валюте транзакции в модуле [processing.py](src/processing.py).
6. Выводите описание транзакций одну за другой из модуля [generators.py](src/generators.py).
7. Генерируйте номера карт в заданном диапазоне чисел из модуля [generators.py](src/generators.py).
8. Используйте декоратор log  в модуле [decorators.py](src/decorators.py) для получения данных об операциях, которые воспроизвелись успешно и не успешно. Результат может быть выведен в консоль или в файл [файл](mylog.txt).
9. Модуль [utils.py](src/utils.py) содержит функции для безопасной работы с данными в форматах Json и логгер, записывающий отчет в [utils.log](logs/utils.log).
10. Модуль [external_api.py](src/external_api.py) содержит функцию конвертации суммы транзакции из USD и EUR в RUB с помощью обращения к внешнему API для получения текущего курса валют. Кроме того, логгер, записывающий отчет в [masks.log](logs/masks.log). 
11. Модуль [tables.py](src/tables.py) содержит функции для безопасной работы с данными в форматах CSV и Excel (XLSX).
12. Модуль [main.py](src/main.py) содержит ф-ию main, которая объединяет логику остальных функций и фильтрует транзакции по запросам пользователя.

## Тестирование:
Наш проект покрыт тестами pytest. Для их запуска выполните команду:
```
pytest -v
```
